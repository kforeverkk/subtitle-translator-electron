# SSA 转 ASS 样式保留设计

## 目标

当 SSA 字幕选择 ASS 双语输出时，将源文件转换为标准 ASS 结构，并尽可能保持源字幕的视觉效果。转换不得静默丢失样式或退回默认 Arial。遇到无法安全转换、且可能改变显示效果的输入时，应停止该任务、保留源文件和 checkpoint，并清楚说明这是 SSA 转 ASS 格式转换问题及具体原因。

## 当前问题

当前保存逻辑只把包含 `[V4+ Styles]` 的字幕视为具有可保留的 ASS 样式。标准 SSA 使用 `[V4 Styles]`，因此会被误判为没有样式，随后用默认 ASS 骨架替代源样式。

SSA 和 ASS 的结构也不能仅靠重命名区段完成转换：样式颜色、透明度、对齐编号和事件首字段均存在语义差异。当前通用解析与写出库还不能无损往返字体、图片附件和其他未知区段，因此这些内容需要采用原文保留策略。

## 推荐方案

新增一个职责单一的 SSA 到 ASS 转换模块，在加入双语样式之前完成标准化。ASS 输入继续沿用现有路径，SRT/VTT 输入继续生成默认 ASS 骨架，避免扩大改动范围。

转换模块执行以下操作：

1. 将 `ScriptType: v4.00` 更新为 `v4.00+`，保留其他脚本信息。
2. 将 `[V4 Styles]` 转换为 `[V4+ Styles]`，并为每个样式生成标准 ASS 字段。
3. 保留字体、字号、主色、次色、粗体、斜体、边框类型、描边、阴影和边距。
4. 将 SSA `TertiaryColour` 映射为 ASS `OutlineColour`。
5. 按 SSA 语义将 `AlphaLevel` 转换到 ASS 颜色 alpha 通道，并处理 SSA 阴影透明度的兼容规则。
6. 将 SSA 对齐值映射为 ASS 九宫格对齐值：`1/2/3` 不变，`5/6/7` 转为 `7/8/9`，`9/10/11` 转为 `4/5/6`。
7. 为 SSA 不具备的 ASS 字段补入不改变原有效果的默认值：下划线与删除线关闭、水平和垂直缩放为 100、字符间距与旋转为 0。
8. 将 Events 的 `Marked` 字段转换为 `Layer`；正常的 `Marked=0` 转为第 0 层。
9. 原样保留对话的 `Text`、`Effect`、时间、样式名、说话人和边距；定位、卡拉 OK、绘图、滚动、横幅及其他行内标签不进行解释或重写。
10. 原样保留注释、字体附件、图片附件、未知区段及不参与转换的原始行，避免通用序列化器改写这些内容。
11. 转换完成后再调用现有双语样式逻辑，为译文和原文创建派生样式。

## 安全边界与错误处理

以下情况视为无法安全转换：

- 缺少 `[V4 Styles]`、Styles `Format` 或可用样式；
- 样式字段数量与 Format 无法对应；
- 被对话引用的样式无法转换；
- 对齐值、透明度或关键颜色字段无效且无法确定等价 ASS 语义；
- Events 缺少必要字段或无法可靠识别对话文本；
- 转换结果无法通过结构校验。

此时不写入或覆盖目标 ASS 文件，翻译任务返回专用错误码。界面显示本地化且可操作的错误，例如：

`SSA 转 ASS 格式转换失败：样式“Sign”使用了无法识别的对齐值 12。原字幕和翻译进度均已保留，请修正源字幕格式或改用 SRT 输出。`

英文界面提供等价信息。错误必须同时包含：

- 明确的 `SSA 转 ASS 格式转换失败` 分类；
- 具体出错的区段、样式或字段；
- 未覆盖原文件、进度仍保留的状态说明；
- 可行的下一步建议。

只影响视觉但可以确定安全默认值的缺省字段由转换器补齐；不能确定语义的值不得静默降级为默认样式。

## 数据与兼容性

转换所需的源格式信息必须随翻译任务和 checkpoint 保存，使暂停、重启和续传后的写出行为一致。现有 checkpoint 仍可读取；如果旧 checkpoint 只保存了解析后的 SSA 数据且缺少安全转换所需的原始信息，应明确报告格式转换错误并建议重新载入原 SSA 文件，不得生成可能丢样式的 ASS。

输出文件命名、语言隔离、重新翻译、原子写入、RPM 限制和成功后 checkpoint 清理机制保持不变。

## 测试与验收

自动测试至少覆盖：

- 多样式 SSA 转 ASS 后字体、字号、颜色、描边、阴影、边距和样式引用保持一致；
- 所有合法 SSA 对齐值的映射；
- `AlphaLevel` 和阴影透明度转换；
- `Marked` 到 `Layer` 的事件转换；
- 定位、颜色、淡入淡出、移动、卡拉 OK、绘图及 `Effect` 内容原样保留；
- 字体、图片附件、注释和未知区段原样保留；
- 双语的译文在上和原文在上两种 ASS 输出；
- 翻译中、续传、配置变化后重启及翻译完成时均不重新引入旧译文；
- 畸形或未知关键字段产生清晰的 SSA 转 ASS 专用错误，且目标文件不被覆盖；
- ASS、SRT、VTT 的既有输出行为不受影响；
- checkpoint 新旧版本兼容。

GUI/E2E 测试应使用隔离的新版应用数据目录，实际载入 SSA 样本执行 ASS 输出，并验证任务成功、输出可解析；另用不兼容样本验证界面显示具体格式转换错误，而不是普通翻译失败。

由于不同播放器和渲染器本身可能存在细微差异，验收以标准字段语义、源标签完整性及主流 libass/ASS 解析兼容为准，不承诺跨所有渲染器逐像素一致。
