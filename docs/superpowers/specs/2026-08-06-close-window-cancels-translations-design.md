# 关闭主窗口时停止翻译的设计

## 目标

关闭主窗口时立即取消所有正在进行的字幕翻译、内容分析、语言检测、自动重试和限流等待，并保留最后一个可靠的 checkpoint。再次启动软件后，用户可以按现有 checkpoint 续传机制继续任务。

## 已确认的产品规则

- 翻译任务只在主窗口存在期间运行。
- 关闭主窗口后，不允许任务继续在后台请求 API 或写入新的翻译结果。
- 已经成功写入 checkpoint 的翻译进度必须保留。
- 正在请求但尚未形成有效结果的批次不计入进度。
- 因关闭窗口而取消的任务不标记为失败或完成。
- 下次打开软件后，继续使用现有的 checkpoint 导入和续传机制。
- 如果内容分析尚未成功保存，下次续传时按现有规则重新分析。
- “关于”窗口继续从属于主窗口并随主窗口关闭。

## 根因

主进程已经为每个活动任务注册 `AbortController`，手动删除任务时也能按任务取消。但主窗口关闭事件只清空窗口引用并关闭“关于”窗口，没有取消活动控制器。

因此 macOS 关闭最后一个主窗口但应用进程仍存活时，翻译请求可能继续执行。同时 `sendProgress` 直接向原渲染进程发送事件，没有检查 `WebContents` 是否已销毁，也没有捕获发送异常。后台任务返回结果后，可能因为向已销毁窗口发送进度而异常中断。

## 方案

### 活动任务注册表

把现有的活动任务控制器映射封装为一个小型注册表，保持现有能力并增加一次取消全部任务的操作：

- `has(taskId)`：拒绝重复启动同一个活动任务；
- `register(taskId, controller)`：注册任务控制器并返回注销函数；
- `cancel(taskId)`：保留现有的单任务取消行为；
- `cancelAll()`：对当前所有活动控制器发出取消信号。

`cancelAll()` 只发出取消信号，不立即清空注册表。任务仍由现有 `finally` 路径释放输入、输出、checkpoint 和 RPM 限制器等资源，避免提前解除路径保护。

### 窗口生命周期

在主窗口的 `close` 事件中调用 `cancelAll()`。该事件发生在渲染进程销毁之前，可尽早终止正在等待的网络请求。

应用整体退出时也调用同一个取消入口，覆盖菜单退出、快捷键退出和非 macOS 的最后窗口关闭流程。重复取消是安全的。

### checkpoint 语义

继续使用现有 checkpoint 写入顺序：

1. 翻译正式开始前先写入初始 checkpoint；
2. 每个批次只有在获得完整、校验通过的结果后才更新字幕对象；
3. 部分输出写入完成后，再把相同进度写入 checkpoint；
4. 取消发生后，活动批次收尾并等待已经排队的 checkpoint 写入完成；
5. 因取消进入异常路径时，不删除 checkpoint，也不发送失败状态。

已经完成全部翻译并进入最终提交阶段的任务可以完成原子输出；尚未到达成功清理阶段的任务保留 checkpoint。不会保存半条字幕或校验失败的模型输出。

### 安全进度发送

所有翻译进度发送先检查目标 `WebContents` 是否已销毁，并捕获窗口关闭竞态产生的发送异常。安全发送只是最后一道保护，任务停止仍以取消信号为主。

关闭窗口导致的取消不会发送 `error` 或 `done`，也不会触发成功次数和赞助提示计数。

## 不改变的行为

- 不改变 checkpoint 文件格式、命名、迁移、备份或清理规则。
- 不改变用户手动删除单个任务时的取消方式。
- 不增加自动恢复任务列表；下次启动仍按当前方式重新选择源字幕或 checkpoint 续传。
- 不改变正常翻译完成、手动重试、并发数、RPM 和 Token 使用策略。
- 不监视运行期间磁盘上的原字幕变化。

## 测试

### 单元测试

- 一个任务可以注册多个控制器，取消该任务会取消全部控制器。
- 取消全部任务会覆盖多个任务，但不会提前解除活动状态。
- 注销后不再取消已经离开的控制器。
- 进度目标已销毁或发送时抛错，不会把异常传播到翻译流程。

### Electron E2E

1. 创建一条字幕并启动真实 IPC 翻译。
2. mock API 完成语言检测，但延迟翻译流响应。
3. 确认初始 checkpoint 已存在后关闭主窗口。
4. 使用隐藏辅助窗口保持 Electron 进程存活，以复现 macOS 的后台场景。
5. 验证翻译 HTTP 连接被主动中止，而不是等待模型响应后才失败。
6. 验证 checkpoint 仍存在，输出字幕没有被后台继续完成。
7. 重新激活主窗口，使用同一任务和配置续传。
8. 验证续传完成、输出正确，并按成功流程删除 checkpoint。

## 非目标

- 不处理源字幕在任务运行期间被外部替换的情况；任务继续使用启动时快照。
- 不调整仅译文的额外语言检测。
- 不调整部分失败时界面进度显示。
- 不处理依赖体积或安全审计告警。
