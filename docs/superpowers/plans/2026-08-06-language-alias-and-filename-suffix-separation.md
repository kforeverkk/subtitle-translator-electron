# Language Alias and Filename Suffix Separation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Preserve broad language-name parsing while limiting removable subtitle filename suffixes to the 27 canonical codes the application actually generates.

**Architecture:** Keep `getLanguageCode()` as the permissive input-normalization boundary. Add a separate canonical generated-code set and a strict filename-suffix predicate, then route single-language, legacy `.translated.<code>`, and bilingual suffix stripping through that predicate.

**Tech Stack:** TypeScript 7, Node.js built-in test runner, Electron, Playwright, pnpm 11.15.1.

## Global Constraints

- Keep all 27 existing output language codes unchanged.
- Continue accepting language names, native names, Simplified/Traditional Chinese aliases, locale forms, `in → id`, and `iw → he` as language input.
- Do not strip language names, locale forms, `in`, or `iw` from filenames.
- Continue stripping canonical single-language codes, canonical bilingual pairs, `original`, `translated`, and `.translated.<canonical-code>`.
- Preserve checkpoint output identity reuse and all existing input/output path protections.
- Do not commit `e2e/screenshots/example.png`.

- [ ] **Step 1: Add failing filename-boundary tests**

Add a test after the existing extended-language mapping test:

```ts
test("only strips canonical codes generated by the application", () => {
  const cases = [
    {
      sourceName: "movie.id.srt",
      expected: "movie.en.srt",
    },
    {
      sourceName: "movie.in.srt",
      expected: "movie.in.en.srt",
    },
    {
      sourceName: "movie.iw.srt",
      expected: "movie.iw.en.srt",
    },
    {
      sourceName: "My.French.srt",
      expected: "My.French.en.srt",
    },
    {
      sourceName: "movie.en-US.srt",
      expected: "movie.en-US.en.srt",
    },
    {
      sourceName: "love.in.la.srt",
      expected: "love.in.la.en.srt",
    },
    {
      sourceName: "movie.translated.en.srt",
      expected: "movie.en.srt",
    },
    {
      sourceName: "movie.translated.in.srt",
      expected: "movie.translated.in.en.srt",
    },
  ];

  for (const { sourceName, expected } of cases) {
    assert.equal(
      getTranslatedPath(
        path.join("subtitles", sourceName),
        "srt-translation",
        undefined,
        sourceName,
        "English"
      ),
      path.join("subtitles", expected),
      sourceName
    );
  }
});
```
